# ⚡ TaskFlow — Modern Task Manager

A sleek, lightweight, and modern Task Management Web Application built with Vanilla HTML5, CSS3, and JavaScript.

---

## 🌟 Features

- 📝 **Create Tasks**: Add tasks with title and custom priority levels (High, Medium, Low).
- 🏷️ **Priority Badges**: Visual indicators for task priority.
- ✅ **Task Status**: Toggle task completion with line-through styling.
- 🔍 **Real-Time Search**: Filter tasks instantly by keyword.
- 🗂️ **Filter Tabs**: Toggle between **All**, **Active**, and **Completed** views.
- 💾 **Persistent Storage**: Uses browser `localStorage` to save your tasks across page reloads.
- 🎨 **Modern Dark UI**: Designed with CSS custom properties, glassmorphism, and responsive layout.
